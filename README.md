# About Me

## What I'm Building

**[accendium.co](https://accendium.co/)** ([source](https://github.com/accendium/accendium-co-web)) - Interactive personal website with a custom
WebGL graphics engine and custom sounds designed in FL Studio.
- Stack: Next.js, TypeScript, Tailwind CSS, WebGL (Raw API), GLSL, Vercel

**[owstats.accendium.co](https://owstats.accendium.co/)** ([source](https://github.com/accendium/ow-stats-ts)) - Overwatch hero statistics
viewer with multi-dimensional queries, live Blizzard API proxying, and a Convex
snapshot pipeline to cache historic data.
- Stack: TanStack Start, React 19, TypeScript, Convex, Recharts, TanStack Table,
  Tailwind CSS v4

**outpaint-py** ([source](https://github.com/accendium/outpaint-py)) - Python CLI tool that iteratively outpaints images using the OpenAI
Image Edit API to produce seamless zoom-out and pan effects through repeated
transform-and-inpaint cycles.
- Stack: Python, OpenAI API
